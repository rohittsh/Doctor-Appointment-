# 🏥 Doctor Appointment Booking System

A modern **Doctor Appointment Booking System** built to simplify the appointment scheduling process for patients, doctors, and administrators. The platform provides a seamless interface for booking appointments, managing doctors, and tracking patient records.

---

## 📌 Overview

The Doctor Appointment Booking System is a full-stack web application that allows patients to book appointments online while enabling doctors and administrators to efficiently manage schedules and appointments.

The system improves the traditional appointment booking process by reducing manual work, minimizing scheduling conflicts, and providing a user-friendly experience.

---

## ✨ Features

### 👤 Patient
- Register and Login
- Browse available doctors
- Book appointments online
- View appointment history
- Update profile information

### 👨‍⚕️ Doctor
- Secure Login
- View scheduled appointments
- Manage appointment status
- Update profile details
- Track patient information

### 🛠️ Admin
- Dashboard with analytics
- Manage doctors
- Manage patients
- Manage appointments
- System administration

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/Doctor-Appointment-Booking-System.git
```

### Navigate to Project

```bash
cd Doctor-Appointment-Booking-System
```

### Install Dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

Admin

```bash
cd admin
npm install
```

---

## ▶️ Run the Project

Backend

```bash
npm run server
```

Frontend

```bash
npm run dev
```

Admin

```bash
npm run dev
```
